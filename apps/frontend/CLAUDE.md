## Architecture

Next.js App Router, TypeScript, Tailwind CSS v4, HeroUI v3 as the UI library.

- `src/app/layout.tsx` — root layout; wraps `children` in `Providers` and sets `suppressHydrationWarning` on `<html>` (required because the theme class is applied client-side).
- `src/app/providers.tsx` — client component wrapping the tree in `next-themes`' `ThemeProvider` (`attribute="class"`, `defaultTheme="system"`). This is the **only** provider here — HeroUI v3 has no `HeroUIProvider` to add (see root `CLAUDE.md`).
- `src/app/globals.css` — `@import "tailwindcss"` + `@import "@heroui/styles"`, plus `@custom-variant dark (&:is(.dark *))` so Tailwind's `dark:` variant follows the `.dark` class `next-themes` toggles on `<html>` (not `prefers-color-scheme` media queries). Theme tokens (`--background`, `--foreground`, etc.) are defined on `:root` and overridden under `.dark`.
- There is **no `tailwind.config.js`/`.ts`** — Tailwind v4 is configured CSS-first via `@theme` blocks in `globals.css`. Don't add a JS/TS config file; extend the CSS instead.
- `src/app/page.tsx` demonstrates importing a HeroUI component (`Button`) directly from `@heroui/react`.

No routing beyond the default `/` page, no API client, no state management is wired up yet.
